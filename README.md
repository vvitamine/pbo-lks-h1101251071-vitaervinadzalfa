## Cara Menjalankan
### Backend
1. Masuk ke folder `rest-api-perpustakaan`
2. Jalankan `php -S localhost:8000 -t public`

### Frontend
1. Masuk ke folder `frontend-perpustakaan`
2. Jalankan `php -S localhost:3000`
3. Buka `http://localhost:3000`
